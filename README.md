# Payment Processing Backend

Backend service for a payment processing application.

The project is being developed as a portfolio application and will support processing and managing payment-related data.

## Tech Stack

* Java 21
* Spring Boot
* Maven
* REST API

Planned technologies:

* Apache Kafka
* Database integration
* Docker
* CI/CD
* Cloud deployment

## Requirements

* Java 21
* Maven

## Running the application

Using Maven Wrapper:

```bash
./mvnw spring-boot:run
```

The application starts by default on:

```text
http://localhost:8080
```

## Project Status

The project is currently under development. Domain requirements and application architecture are being defined incrementally.
